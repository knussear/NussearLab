# Nussear Lab Website

A website for the Nussear Lab at the University of Nevada, Reno, featuring information about lab members, research projects, publications, and news.

## About

The Nussear Lab at the University of Nevada, Reno is dedicated to advancing research in ecology, conservation biology, and wildlife management. This website serves as a central hub for tracking:

- **People**: Lab members, students, and alumni
- **Projects**: Current and completed research projects
- **Publications**: Scientific publications from the lab
- **News**: Latest updates, achievements, and events

## Website Structure

The website consists of the following pages:

- `index.html` - Home page with lab overview
- `people.html` - Lab members and alumni
- `projects.html` - Research projects
- `publications.html` - Scientific publications
- `news.html` - Lab news and updates
- `css/style.css` - Website styling

## Getting Started

To view the website locally:

1. Clone this repository
2. Open `index.html` in a web browser

No build process or dependencies are required - this is a static HTML/CSS website.

## Deployment

This website can be deployed to any static hosting service, including:

- GitHub Pages
- Netlify
- Vercel
- Any web server

For GitHub Pages deployment, enable Pages in the repository settings and select the main branch.

## Updating Content

To update the website content:

1. Edit the relevant HTML files (`index.html`, `people.html`, `projects.html`, `publications.html`, `news.html`)
2. Update information in the appropriate sections
3. Commit and push changes

The website uses semantic HTML and is structured to be easy to edit without requiring web development experience.
