# NussearLab Website

A professional website for the Nussear Lab at the University of Nevada, Reno, showcasing research, people, publications, projects, and news.

## Features

- **Homepage**: Lab overview and welcome message
- **People**: Lab members, students, and alumni
- **Publications**: Searchable list of research publications with year filtering
- **Projects**: Current and completed research projects
- **News**: Latest updates and announcements
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Easy to Update**: Simple HTML structure for content updates

## Quick Start

1. Open `index.html` in a web browser to view the site locally
2. Edit HTML files to update content
3. See `WEBSITE_GUIDE.md` for detailed instructions

## Deployment

### GitHub Pages

This site is ready to deploy on GitHub Pages:

1. Go to repository Settings > Pages
2. Select the branch to deploy (e.g., `main`)
3. Select root folder `/`
4. Save and your site will be live at `https://yourusername.github.io/NussearLab/`

### Other Options

The site can be hosted on any web server, Netlify, Vercel, or university hosting services.

## Updating Content

See `WEBSITE_GUIDE.md` for comprehensive instructions on:

For bulk importing publications from ResearchGate or other sources, see `IMPORT_PUBLICATIONS.md`
